# Definition of Done
A story is Done only when:
- Acceptance criteria and FR/NFR links have been satisfied.
- Relevant automated tests pass and manual device QA is documented.
- Privacy and accessibility considerations are checked.
- Edge/error states are handled; no silent data changes.
- No user data or keys are committed.
- Architecture/SRS/backlog updated when behavior changes.
- A reviewed PR is merged, and the product owner accepts the demonstrated behavior.
A scaffold or mocked UI is not a completed feature.
