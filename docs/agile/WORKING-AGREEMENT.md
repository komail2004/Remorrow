# Agile Working Agreement
- One prioritized product backlog; weekly refinement and sprint planning.
- Each story has business value, requirements traceability, a specific testable acceptance condition and relative estimate.
- Keep WIP low; issues move Backlog -> Ready -> In Progress -> Review -> Done.
- Git workflow: main protected when possible; feature branches `feature/RM-###-name`, PR review and CI before merge.
- Definition of Ready: understood scope, dependencies, acceptance tests and reasonable size.
- Definition of Done: functionality, tests, accessibility, error states, docs and PR review.
- Demo an end-to-end working slice at each sprint review; run retrospective and adjust backlog.
- Use real dates/metrics only when measured; log risks and unresolved decisions openly.
