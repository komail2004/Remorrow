# Contributing
1. Select a backlog issue and verify its FR/NFR traceability and acceptance criteria.
2. Branch from main: `feature/RM-###-short-name` or `fix/RM-###-short-name`.
3. Write tests for logic and permission/error cases; keep code small and reviewed.
4. Update PRD/SRS/backlog when behavior changes.
5. Open a pull request with screenshots, manual QA notes, risks and linked issue.
6. Merge only after review and the Definition of Done. Never commit secrets, receipts or personal screenshots.
