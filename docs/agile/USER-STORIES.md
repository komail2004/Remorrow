# User stories
- As a busy user, I can paste a message and get a proposed event so I don't retype it.
- As a student, I can share a screenshot and turn the relevant deadline into a reminder.
- As a shopper, I can confirm a return deadline and receive advance alerts.
- As a privacy-conscious user, I can process content offline and delete local copies.
- As a user with accessibility needs, I can operate capture/review/save using VoiceOver and large text.

Each story maps to a specific RM-### issue in the backlog; detailed criteria are stored with the implementation ticket.
